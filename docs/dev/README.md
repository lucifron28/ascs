# Developer Documentation

This folder contains operational notes for contributors and maintainers. It is
separate from the thesis, defense, and user-facing system documentation in
`docs/`.

## Contents

- [`ACCEPTANCE_TESTING.md`](ACCEPTANCE_TESTING.md) — test layers, emulator safety, fixtures, and acceptance commands.
- [`PROJECT_CONTEXT.md`](PROJECT_CONTEXT.md) — active architecture and workflow context for implementation work.
- [`UX_ACCESSIBILITY_QA.md`](UX_ACCESSIBILITY_QA.md) — automated UX, accessibility, responsive, keyboard, and print evidence.
- [`VERCEL_DEPLOYMENT.md`](VERCEL_DEPLOYMENT.md) — non-secret demonstration deployment record and verification notes.

Keep credentials, private keys, emulator exports, and other local-only artifacts
out of this folder and out of the repository.
