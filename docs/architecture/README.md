# Architecture Assets

The source-aligned architecture narrative is in
[`../TECHNICAL_ARCHITECTURE.md`](../TECHNICAL_ARCHITECTURE.md).

The editable PlantUML sources and rendered assets are in:

- [`../diagrams/src/`](../diagrams/src/) - self-contained `.puml` sources.
- [`../diagrams/svg/`](../diagrams/svg/) - manuscript/presentation-friendly SVG.
- [`../diagrams/png/`](../diagrams/png/) - preview PNG files.

Regenerate the diagrams from the repository root with:

```bash
npm run docs:diagrams
```
